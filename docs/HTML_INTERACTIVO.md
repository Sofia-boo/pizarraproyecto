Usá **＋ → HTML interactivo** para insertar archivos `.html` o `.htm` de hasta 1 MB. Botones, formularios y JavaScript funcionan dentro del elemento al usar el selector. Movelo desde el encabezado y agrandalo desde la esquina inferior derecha. La goma sólo borra tinta. El encabezado permite eliminar el HTML; Deshacer lo recupera. También admite selección, copias, capas, respaldo y sincronización como objeto de la pizarra.

El documento se guarda completo con la pizarra. Para usar imágenes, estilos y scripts sin conexión deben estar incluidos en el propio HTML (por ejemplo imágenes data URL). Los archivos externos y rutas relativas a carpetas de la computadora no se importan. Las modificaciones internas de formularios o de variables JavaScript duran durante esa sesión; al recargar la pizarra el documento vuelve a su estado inicial.

Se ejecuta en un [iframe con sandbox](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/iframe#sandbox): se permiten scripts, formularios y descargas, conservando un origen aislado. No se habilita acceso al documento, almacenamiento ni credenciales de la pizarra, navegación de la ventana principal o ventanas emergentes. La selección por la pizarra y su menú contextual se usan sobre el encabezado; el contenido conserva sus propias interacciones. La vista impresa no captura la ejecución del iframe.
