# Ejes cartesianos

Agregalos desde **Formas → Ejes cartesianos X e Y cuadriculados**. Este elemento ya no abre el editor de texto «Elemento académico» ni muestra «Editar elemento».

Arrastrá una punta del eje X para cambiar el ancho o una punta del eje Y para cambiar la altura. Los círculos resaltan las puntas al seleccionar el plano. El origen queda fijo, la cuadrícula se escala con cada eje y la numeración conserva el rango original. También funciona después de girar el plano, con mouse, lápiz o un dedo sobre la punta. Fuera de las puntas, los gestos táctiles conservan el desplazamiento habitual.

La esquina del selector permite agrandar el plano completo como antes. Los cambios se guardan localmente, admiten Deshacer/Rehacer y se sincronizan en una pizarra compartida. Cancelar un arrastre restaura el tamaño anterior. Los editores de notas, matrices y código permanecen disponibles.
